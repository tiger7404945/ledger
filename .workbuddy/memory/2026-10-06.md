## 概念答疑：软件设计中的「分区」

- 用户问「软件设计中的分区指什么」→ 用两张图 + 文字解释：**一个账号在本机对应的一个
  完整 IndexedDB 库**（不是表、不是字段前缀），切分维度 = 账号身份。
- 三样易混的东西讲清：① 本地库分区（`core/idb.js` 的 `partitionedDbName`）
  ② 云端 `_id` 别名前缀（`core/cloudId.js` 的 `accountPrefixOf`，与 ① 共用同一前缀）
  ③ `DB_VERSION`（库结构版本，与 `SCHEMA_VERSION` 是两回事）。
- 核心论证（画成了图）：**数据能按 `_openid` 过滤，但本地待推队列 outbox 不能** ——
  队列的归属由「推送那一刻的登录态」决定，不由条目自身字段决定，所以只能在存储层隔离。
- 关键机制重申：`rebuildForAccount()` 三步（停旧引擎 → 换指针 → 返回新引擎）里
  **停旧引擎是硬约束**；`bucketCache` 跨切换保留；装配层 `migrateFrom: false`。

## 审查云函数 ledger-sync-stamp 的调用栈（发现一处契约漂移）

- 用户要求查看该云函数的调用栈 → 读 `cloudfunctions/ledger-sync-stamp/index.js`（253 行）
  + 客户端侧全链路，画出分层调用栈图。
- 完整链路：`syncEngine.run()` → ⓪`resolveClockOffset()` → ①`pullAll()` →
  ②`pushPending()` → `cloud.push()` → `cloudbaseAdapter.push()` →
  `fetchServerStamps()` → **HTTP POST 网关** → 云函数 `exports.main()` →
  `parseUpdates()` → `where().get()` 查存在性 → `doc().update()` 写
  `{serverUpdatedAt, _serverTs}`。
- **发现的不一致（两层，都静默）**：
  1. `cloudbaseAdapter.push()` 第 519 行 `await fetchServerStamps(...)`
     **没有接收返回值**，函数返回的仍是 `{ upserted, rejected }`（第 522 行），
     **不含 `stamps`**。而 `syncEngine.js:210` 读的是 `result.stamps`。
  2. 更深一层：**即使接住也用不了** —— `fetchServerStamps` 返回的 Map 其 key 是
     **云端别名**（调用处传的是 `aliasesToStamp`），而 `idbAdapter.applyStamps`
     第 983-987 行按**本地 id** 查 `byId.get(id)` → 永远 miss。
  3. 测试为何全绿：`fakeCloud` 第 202 行 `stamps[id] = stamped` 用的是**本地 id**
     （fake 云端不用别名），形态与真云端不一致 → 「后端可替换」原则漏在了
     **返回值的 id 空间**上。
- **影响评估（不是丢数据 bug）**：刻度回写本地还有第二条路 —— 云函数盖刻度时
  顺带刷新了 `_serverTs`（index.js 第 220 行），下次 pull 必然重新拉到该文档
  （`_serverTs > 水位线`），`fromRemote` 保留 `serverUpdatedAt` → `applyRemote` 落库。
  只是**延迟一个同步周期**。且 `effectiveServerStamp` 的失效判据（内容比刻度新则
  刻度作废）让「本地暂时没刻度」不会导致误判。
- 结论：**冗余路径失效 + 契约漂移**，功能无碍。修法给了用户（接住 Map + 把 key 从
  别名映射回本地 id），**未擅自改代码**，等确认。

## S9 修补：push 刻度回传的契约漂移（用户确认后执行）

- **代码**（`src/api/adapters/cloudbaseAdapter.js`）：`push()` ③ 段现在
  `const stamped = await fetchServerStamps(...)` 接住返回值，用
  `localIdOf = new Map(upserted.map(id => [toCloudId(id, prefix), id]))` 把**别名 key
  换算回本地 id**，返回 `{ upserted, rejected, stamps }`；空列表分支也补成
  `{ upserted: [], rejected: [], stamps: {} }`（形状稳定）。
- **契约**（`src/api/sync/cloudClient.js`）：push 段声明 `stamps`，并写明
  「key 必须是本地 id」「可缺省/为空对象、适配器不得因此抛错」。
