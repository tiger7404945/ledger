- 分类角标（含二级分类的小圆点）由 `CategoryIcon` 的 `badge` 属性渲染；页面按 `hasChildren` 计算。

### 验证坑（重要，已更新）
- `agent-browser` 的 localStorage 在同一浏览器实例内是**持久**的，但**页面历史每次 `open` 都会重来**（`history.state.back` 为 null）。所以验证「离开 → 返回」这类导航行为，必须在**同一个页面内**用真实点击（`.tab.is-add`、`button[aria-label="返回"]`）或 `history.back()` 完成；用 `location.hash = '...'` 手工改 hash 属于绕过 vue-router，拿不到它的 history state。
- `eval` 对某些表达式会**挂起不返回**（尤其带 `.filter(function(){...})`、模板较长的脚本）。用法上：给每个 `eval` 套 `timeout`，或**干脆别用浏览器验数据层**。
- **数据层逻辑改用 Node 直跑最省事**：`package.json` 是 `"type": "module"`，adapter 只依赖相对路径模块，因此可以用 `globalThis.localStorage = {getItem/setItem/removeItem}` 打桩 + `await import('file:///D:/projects/ledger/src/api/adapters/mockAdapter.js')` 直接断言。脚本示例见 `.preview/migrate-test.mjs`（11 条断言全绿）。
- 判断「页面是否恢复」不能只比截图哈希：草稿恢复到 cat_food 与全新默认渲染**像素完全相同**，必须读 localStorage 内容或看有辨识度的字段（备注、金额）。
- 写批量浏览器脚本时，**不要**给可执行文件路径加转义引号（`\"$N\"` 会被当成带字面引号的命令名而静默失败），直接 `N=路径` 然后 `$N` 使用。

## 修复：备注候选看不到 + 退出记账页应作废草稿

### 问题 1：填写备注时看不到历史备注
**原因不是代码，是数据**：演示账单的 `remark` 是后加的字段，而 `ledger.db.v1` 只在 `schemaVersion` 不匹配时重新播种，所以早期播过种的浏览器里那些 `bill_seed_*` 账单备注全为空 → `remarkHistory` 查不到任何东西。
（同日早前已在回复里说过「点重置演示数据」，但那要求用户手动操作，体验不闭环。）

**修复（非破坏性迁移）**：
- `seed.js` 导出 `SEED_BILL_NOTES`（账单 id → 备注）与 `SEED_NOTES_VERSION`；补差额那笔的备注提为 `GAP_BILL_REMARK` 常量，避免两处硬编码。
- `mockAdapter.js` 新增 `migrate(state)`，在 `load()` 读到已存在的库后执行：只给「seed 账单 id + 备注为空」的记录回填，`state.meta.seedNotes` 打标记保证幂等，**不动用户自己记的账**。`buildSeed()` 自带 `meta.seedNotes`，新库无需迁移。
- 结论：老数据不用点重置也能看到候选；选择 bump `SCHEMA_VERSION` 会清空用户数据，**以后加演示字段一律走这种回填**。

### 问题 2：退出记账页后不该保留草稿
**原实现**是「任一字段变化即落盘 + 只在保存/删除/重置时清除」，于是任何离开方式都会把草稿留到下次进入。

**新策略**（单点裁决，`useRecordDraft.js` 的 `installRecordDraftGuard(router)`，在 `src/router/index.js` 装配）：
- `to.path` 不在 `/record` 或 `/category*` → `clearRecordDraft()`；
- `to.path === '/record'` 且 `from.path` 不以 `/category` 开头 → 也清空（覆盖首次打开、刷新、从首页/账单页进入）。
- 即**只有「记账页 ↔ 分类管理/分类编辑」往返会恢复草稿**，其余退出方式一律作废。`RecordView.onMounted` 里的 `readRecordDraft` + `editingId` 比对保留，作为第二道校验。
- 代价：**刷新不再恢复草稿**（这是本次需求要的语义，原「刷新也能恢复」的说法已作废）。
- 实测：填「交通-停车费 + 往返测试 + 12」→ 进分类管理（草稿仍在）→ 返回（备注/金额原样）✓；左上角返回退出后草稿为 `null`，再进记账页是干净的「餐饮 / 0.00 / 空备注」✓。
