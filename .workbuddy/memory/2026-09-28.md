## 随手记账 H5 · 第一阶段前端复刻（Vue3）

- 依据 8 张参考截图完成移动端记账 App 前端，工程位于 `D:\projects\ledger`。
- 技术栈：Vue 3.5 + Vite 6 + Vue Router 4（hash）+ Pinia，无第三方 UI 库、无图标库（自建 ~100 个 SVG 线性图标）。
- 交付物：`page-structure.md`（页面内容/交互真相源）、`ui-implementation-plan.md`、`README.md`。

### 关键技术决策
- **数据层契约化**：`src/api/contract.js` 定义实体与 Repository 契约；`mockAdapter`（localStorage 持久化）为当前实现；`idbAdapter`（含 IndexedDB 建库与索引定义）、`leancloudAdapter`（含 Class 设计与冲突策略）为预留骨架。切换数据源只需改 `src/api/index.js` 的 `DATA_SOURCE`。
- **outbox 增量队列**：`src/api/sync/outbox.js`，所有写操作 local-first 入队，供后续云端推送。
- 所有 adapter 方法均为 async，视图/store 不感知实现。
- **手机外框**：`.app-frame` 用 `transform: translateZ(0)` 作为 `position: fixed` 的包含块，使底部栏/弹层约束在 430px 内。
- 布局骨架：每个页面为 flex 列（header / 可滚动 body / footer），实现真正的分区滚动而非整页滚动。
- 金额显示不带千分位、`¥` 小一号，与参考设计一致。
- 分类角标（含二级分类的小圆点）由 `CategoryIcon` 的 `badge` 属性渲染；页面按 `hasChildren` 计算。
- 图标选择器左右联动：右栏 scroll 计算 `offsetTop` 高亮左栏，左栏点击 `scrollTo`。

## 记账页二级分类面板两项修复

用户反馈：选中二级分类时一级分类图标不亮；二级分类区与一级分类区区分不明显。

**排查方法**：用 PIL 对参考稿 `微信图片_20260927231958_14_4.jpg`（1080×2400）做像素采样，而不是凭肉眼判断：
- 整页底色 `#f4f4f4`（一级分类区也直接铺在这个灰底上，没有白色容器）
- 二级分类面板是白色 `#ffffff` 浮起卡片，横向内缩 84/1080 ≈ 7.8% 每侧，圆角约 18 物理像素，下边缘有极轻阴影

**结论**：原实现把 `RecordView` 页面底色写成了纯白，白色面板因此"消失"——这是区分不明显的根因，不是面板底色不够深。

**改动**：
1. `CategoryGrid.vue` 新增 `activeId` prop + `isActive()`，选中态 = `selectedId || activeId`。
   `RecordView` 改为 `:selected-id="subId"` `:active-id="primaryId"`（原先传的是 `subId || primaryId`，二级 id 在宫格里匹配不到，导致父级不亮）。
2. `RecordView` 页面底色 `#fff` → `var(--page)`；`.record-body` 背景改透明；底部分类键盘面板保持白色。
3. `SubCategoryPanel` 新增 `--surface-raised` 底色 + 左右 24px 内缩 + `--r-md` 圆角 + `--shadow-card` + `--hairline` 描边。
4. 顺手修 bug：切换支出/收入/转账/借贷时未清空 `primaryId/subId/expandedId`，会把上一个类型的分类带过去（可能存错分类）。新增 `switchType()` 在切换时重置。
