### 评估结论（通过）
- 腾讯云开发 CloudBase：国内访问快、合规、有免费额度，且**前端静态托管与后端同平台**，省掉跨域与域名配置。
- **免费体验版**：每账号限 1 个环境，3,000 资源点/月（1,000 点 ≈ ¥1），**单次续期 6 个月、不支持自动续费**，过期停用 → 已在计划里要求设续期提醒。
- 数据库选**文档型**（数据是嵌套对象、不需 JOIN；Web SDK 直连最成熟）；权限用**安全规则** + 自动注入的 `_openid`（`doc._openid == auth.openid`）。
- 幂等键：云端文档 `_id` 直接用本地 id；字段名保持 camelCase 同名，省掉关系型那层映射与触发器。
- 已知坑写进计划：Web 端必须把域名加进「安全来源」，否则第一次调用就失败。

### 踩到的坑
- **IndexedDB 的 `getAll` 按主键序返回**，内存数组是插入序 → 两个适配器快照顺序不同。这暴露了一个真问题：`filterCategories` 只按 `order` 排序，而 `order` 只在同级同类型内唯一，相同 order 时顺序取决于底层存储 → **已加 id 兜底**，让排序稳定且两适配器一致。
- 测试断言写错一处（把随机生成的 `parentId` 当稳定值比），改为断言「父 id 等于刚建的一级分类 id」。
- **同 hash 的 `open` 不会重载模块**，导致「清空 localStorage 后看不到重新播种」的假象；验证再播种必须用 `reload`。
- 浏览器验证的黄金判据：创建一笔后 **IndexedDB bill 44 → 45 而 localStorage 旧库仍是 44**，这才证明数据真写进了 IndexedDB。
